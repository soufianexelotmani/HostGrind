# Phase 6 checkpoint plan

Each checkpoint starts by inspecting the worktree and the last recorded evidence. After each build, migration review or test run, record commands, counts, database status, modified files and unresolved decisions in [progress](PROGRESS.md). Keep prior tests, use disposable SQL Server fixtures and fictitious browser data, and get explicit approval before advancing. Endpoint names and future file groupings below are proposals. The tenant route prefix is `/api/v1/organizations/{organizationId}`.
